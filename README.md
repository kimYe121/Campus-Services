# 校园百事通 (Campus Services Hub)

一个基于 AI 赋能的新一代高校智慧校园小程序。致力于将传统“人找流程”的繁琐服务大厅，升级为“流程找人”的智能化、透明化校园民生服务底座。

## 🌟 核心亮点

- **AI 一句话办事**：告别繁琐的入口查找，首页输入一句话（如“宿舍空调不制冷”），AI 自动识别意图、分流部门并预填表单草稿。
- **智能表单与材料校验**：动态联动的表单设计，配合 AI 智能对话补全缺失信息。上传证明材料时支持“完整度评估”与“自动质量检测”，避免因材料不全导致的反复退回。
- **全透明的进度摘要**：工单详情页引入“AI 进度摘要卡”，直观展示当前状态、预计下一步时间，并提供基于 SLA 的“一键智能催办”与“升级”功能。
- **双身份权限解耦**：一套系统，两套视图。严格隔离学生与教职工的数据和权限（如学生独占“请假申请”，教师独占“教学场所预约”）。
- **百事圈功能社区**：内置类似 QQ 频道的互助论坛，支持将讨论无缝“一键转为官方事项”，形成社区互助到官方工单的治理闭环。

## 🛠 技术栈

- **前端框架**: [Taro 4.x](https://taro-docs.jd.com/) (React 技术栈)
- **状态管理**: Zustand
- **样式方案**: Tailwind CSS (通过 CSS Modules 与 SCSS 深度定制)
- **UI 设计**: 遵循移动端优先的轻拟物卡片式设计 (Glassmorphism & Brutalism 融合)

## 📦 本地运行与构建

### 1. 环境准备
确保您的本地环境已安装 [Node.js](https://nodejs.org/) (建议 v18+) 和 npm。

### 2. 安装依赖
```bash
npm install
```

### 3. 本地启动 (H5 网页预览)
```bash
npm run dev:h5
```
运行后，在浏览器中打开控制台输出的地址 (通常为 `http://localhost:10086/`) 即可预览。

### 4. 构建静态文件 (用于 GitHub Pages 等静态托管)
```bash
npm run build:h5
```
构建产物将输出在 `dist/` 目录中。

## 📱 模拟演示指南

1. **登录测试**：
   - 输入长度小于8位或以 `T` 开头的账号（如 `T8801`），系统将识别为**教职工身份**。
   - 输入其他常规学号（如 `20230001`），系统将识别为**学生身份**。
   - 体验带物理拖拽惯性的**现代化滑块验证码**。
2. **体验 AI 一句话办事**：
   - 在首页搜索框输入：“我要开在读证明去大厂实习”，点击发送，观察 AI 识别结果卡片及表单预填。
3. **全局 AI 导办悬浮窗**：
   - 拖拽右下角的 🤖 悬浮球，点击进入对话，输入“怎么交学费？”，体验智能卡片推送。如果隐藏了悬浮窗，可在“我的”页面一键恢复。
